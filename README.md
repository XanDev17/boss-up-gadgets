# Boss Up Gadgets

I want to make the store front minimal and professional, using Boss Up Trades brand colors and logo across the storefront and admin dashboard. Use deep navy #021A30, teal #087F98, cyan #98EEFE, and warm off-white #FFFDF8. Create a full ecommerce gadget store with Home, Shop, About, product details, cart/checkout, WhatsApp ordering, and a private Admin dashboard. The public menu should be clean and contain only Home, Shop, About, and cart; Admin must not appear anywhere on the public site or footer. Do not add a floating or scroll-triggered support/chat button. Home should be a discovery page, not a duplicate of the full Shop: include a featured gadget carousel with a Shop Now action, category shortcuts, New Arrivals in a 2x2 product grid, a small blog/gadget-tips preview, and footer. Shop should have the minimal filtered products view with a left sidebar on desktop for category, price, rating and sort filters, clear-filter control, grid/list toggle, and three-column gadget product cards in grid mode; list mode shows horizontal product rows. On mobile, keep the menu clean, put filters in a drawer, and allow toggling between list and a 2x2 product grid. Tapping a product opens a product detail view with image, category, name, rating, discounted price, description, feature checklist, stock status, quantity control, Add to Cart, and Save to Wishlist. Include both cart checkout and WhatsApp ordering. Add an About page and a simple footer with shipping, terms, and copyright links. Build a separate private Admin dashboard with sales, orders, inventory metrics and multiple graphs plus low-stock products. Use clear, professional layouts on both desktop and mobile. The exact logo asset and real store data have not been supplied, so use a clean text-based Boss Up Trades wordmark and clearly sensible sample gadget products/data that can be replaced. Make the finished store ready to publish.
